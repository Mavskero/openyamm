## 完整运行资源

本发布提供以下六个运行文件，接收端应作为一整组使用：

- `engine.zip`
- `conversion.json`
- `mm6.zip`
- `mm7.zip`
- `mm8.zip`
- `mmmerge.zip`

共享UI表为214键，其中146项来自原始文字，68项为明确登记的项目译文。
Combat资源包含223的累计反馈文字，导航包含222恢复的MM8原生基础表。
此前的休息动画、滑条、字体及其他完整资源继续保留。

四个world与固定214及195相同，但仍随本次tag全部提供，便于完整下载和独立校验。
MM6/MM7/MM8在190已有累计改动，不能从RC2旧包替代这四个world中的对应文件。
本次直接提供完整资源，无需按216–229的历史说明逐批修改engine成员。

组装后的目录应为：

```text
assets-229/
  engine.zip
  conversion.json
  SHA256SUMS
  worlds/
    mm6.zip
    mm7.zip
    mm8.zip
    mmmerge.zip
```

GitHub Release附件平铺下载。先将完整附件保留在同一个新下载目录，校验附件清单，
再把四个world ZIP复制进资源目录的 `worlds/` 子目录，最后按资源清单再次校验。
下面的 `/ABS/` 需要替换为接收Mac的真实绝对路径；命令在完整下载结束后执行：

```sh
cd /ABS/downloads-229
shasum -a 256 -c ARTIFACT-SHA256SUMS
mkdir -p /ABS/assets-229/worlds
cp engine.zip conversion.json SHA256SUMS /ABS/assets-229/
cp mm6.zip mm7.zip mm8.zip mmmerge.zip /ABS/assets-229/worlds/
cd /ABS/assets-229
shasum -a 256 -c SHA256SUMS
```

`SHA256SUMS` 保留 `worlds/` 相对路径，平铺目录不能直接替代上面的资源目录结构。
六个运行文件中的ZIP保持压缩状态；向App选择整个 `assets-229/` 目录。
保留旧资源目录，不混用旧engine、历史增量清单、源码素材或开发夹具。
资源导入不会自动把存档放进游戏槽位。

源码包包含项目代码、配置、文档和构建所需源资源；运行素材由六文件提供。
第三方依赖按固定版本获取，不附旧build、CMakeCache、DerivedData、签名材料或用户存档。
