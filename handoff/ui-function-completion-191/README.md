# 基础 UI 与功能集中修复（191）

本批修复长中文内容看不全、短按丢失、上层取消误进菜单、保存失败缺少反馈，以及制作人员按钮无内容的问题。
三个子代理完成互斥模块开发，主代理统一整合和构建。它是一次集中源码提交，没有新 Release 或设备检查点。

## 已完成的修改

- 长消息卷宗按实际字形宽高分页，松手后保持打开，支持点击、方向键、PageUp/PageDown 和滚轮翻页。
  正文使用对称边距，标题可换行；翻页和关闭不把手势传给下方头像、背包或世界。短卷保留持读行为。
- NPC 长中文选项使用实际字形行高；绘制与点击共用几何区域。内容超过一页或五项时仍可访问，
  键盘选择会切到对应页，原始动作索引保持不变。
- 读档、设置、按键绑定、Arcomage、休息、旅行、箱子和普通 NPC 确认支持完整短按。
  对话用输入帧标识消费开启手势，避免同一确认继续跳过新对话；箱子保留重绑开箱键的初始按住状态。
- 移动检查按钮按住时，第二根手指的完整短触保留检查坐标；松开、取消和失焦清理状态，避免误点击。
- 银行金额编辑时数字 1–5 不再切换队员；数字、退格和确认支持短按，金额使用宽整数解析后限制范围。
- 法术目标选择层优先处理取消；法术详情的 Escape 只关闭详情，保留法术书。
- 日志显示页码钳制后回写，避免末页多按 Next 后需要重复 Previous 才能返回；支持短按 Escape。
- 存档目录创建、查询和枚举失败返回可取消界面。保存先独占写入同目录临时文件，完整写入并同步后
  原子替换，不先截断原档；损坏或不可读的既有文件不会被隐式覆盖。失败时清理本次临时文件。
- 手动保存的预览或真实写入失败在保存页显示，快捷存读档也有 HUD 反馈；错误时保留退出入口。
- 主菜单“工作人员名单”接入所选原始 LOD 的 Credits.txt，保留姓名和顺序；支持分页、滚轮、键盘与返回。
  旧资源缺少原名单时显示真实项目信息及缺失提示。

## 继续修复：卡牌触控与小窗口详情

进一步确认了三个可以脱离设备处理的问题，已集中实现：

- Arcomage 的触摸弃牌此前仅在 Android 编译，iOS 触摸按下直接尝试出牌，主动弃牌只能右键。
  现按实际触摸来源使用共享处理：轻点松手出牌、上划弃牌，完整同帧拖拽也保留起止位置。
