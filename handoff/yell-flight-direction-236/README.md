飞行生物被Yell触发逃跑后，现在保留该次朝Party采样得到的pitch，不再被每帧的当前战斗目标或追击高度覆盖。仅这次持续Flee携带typed可选Z分量，包含有效零值；普通Fear／低HP逃跑、水平XY、资格、时长与随机抽取次数保留。受击、新动作、到期、死亡、复活、移除和地图重入会清除，室内外共用AI消费。

规则来自已持有的原MMerge `mm8.exe`（SHA256 `97be86a7597fbd9763f9b4b0ed1f4a7e47c960703fa30857c32daa056b7d403b`）。Yell→Flee链为`0x42e78d → 0x438856 → 0x402a6b`，从`actor.Z+0.75×BodyHeight`朝`Party.Z+1`计算飞行pitch。`0x46f376–0x46f40d`消费yaw生成XY、sin(pitch)生成Z，水平不乘cos(pitch)。没有套用直觉的三维归一化或`+512`追击高度。标准合并树精本来是stand且被原与当前Yell共同排除，未证明新缺口，因此未改怪物ID或树精规则。
