## 修改

- 新建队伍取消返回原游戏菜单；读档或已确认的新建因资源加载失败时，保留并恢复原队伍、地图、时间、手持物品、待处理事件及未保存状态。恢复不重跑地图进入事件或定时刷新。
- F9/F10同帧按下并松开仍能触发；目标型卷轴与道标选择保留临时等级、精通和免耗魔上下文。
- 商店偷取容量探测不再使库存指针失效；出售、鉴定、修理需按下与释放落在同一物品，拖开取消。触摸检查修饰键先按下时，后到达的目标仍可执行一次物品合成/使用。
- 银行金额输入增加可见提交/取消和键盘避让区域；余额、存款、提款和金额提示使用原版文字。商店物品界面不再执行隐藏的上级键盘选项。
- 等待新按键时，键位设置的返回、默认和翻页仍正常工作；新建、加载、保存及设置根布局可缩小到实际窗口内，绘制和点击使用同一坐标。
- 超长存档名按UTF-8边界显示省略号；编辑时保留可见尾部和光标，不改存储值。
- 通关证书的标题、角色、分数、时间采用原版文字，MM8结尾段明确为项目中文翻译；长角色名在证书及Arcomage面板内适配。原版证书背景恢复、浅色纸张用深色字，Merge深色结束画面仍使用白字。
