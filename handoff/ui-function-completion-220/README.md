# 220：普通 NPC 确认按钮中文

队员加入确认、雇佣确认以及生成佣兵的加入入口，共五个按钮，使用当前语言的“是／否／加入”。字幕来自原始 GlobalTxt 704、705、122，缺少 UI 表时保留原有英文回退。

共享 UiText 从119项扩展为122项，仍接受完整的旧119项及已有旧版本前缀。按钮的 ActionKind、id 和 offer 不变；NpcDialogTable 用于机制识别的源字符串 `Join` 保留。

本批只需原生构建、原始核心资源导入及通用 unsigned iOS 构建。没有新测试用例、App运行、招募或战役回放、设备操作和发布包。当前完整开发资源以218为底，只更新 `data_tables/ui_text.txt`；其余档案成员及世界包保留，Save104不变。

219首次专家长剑训练的实际UI记录与本批源码一起推送；固定214发布、195和RC1–3不变。

本批属于源码、资源与构建验收，尚无这五个按钮的新像素或iPad验证。完整自然通关仍未证明，完整目标保持active，工程估算约85%，置信度低。

原生构建70.969秒、核心导入0.193秒、单成员资源组装2.186秒、通用unsigned iOS构建58.362秒均通过。
